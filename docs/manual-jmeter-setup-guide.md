# JMeter多用户测试手动配置指南

## 🎯 概述

由于XML文件可能存在兼容性问题，这里提供手动配置JMeter的详细步骤，确保多用户测试能够正常工作。

## 📋 手动配置步骤

### 步骤1：创建测试计划
1. 打开JMeter
2. 右键点击"测试计划" → 选择"添加" → "线程（用户）" → "线程组"
3. 重命名线程组为"多用户页面测试线程组"

### 步骤2：配置线程组参数
在"线程组"中设置：
- **线程数（用户数）**：1000
- **启动时间（秒）**：60
- **循环次数**：1
- **调度器**：不勾选

### 步骤3：添加CSV数据文件配置
1. 右键点击"线程组" → "配置元件" → "CSV数据文件设置"
2. 重命名为"用户数据文件"
3. 配置参数：
   - **文件名**：`docs/test-users.csv`
   - **文件编码**：UTF-8
   - **变量名称**：`phone_number,password`
   - **分隔符**：`,`（逗号）
   - **忽略首行**：勾选
   - **循环使用**：勾选
   - **遇到文件结束符时停止线程**：不勾选

### 步骤4：添加HTTP请求默认值
1. 右键点击"线程组" → "配置元件" → "HTTP请求默认值"
2. 配置参数：
   - **协议**：http
   - **服务器名称或IP**：localhost
   - **端口号**：3002

### 步骤5：添加登录请求
1. 右键点击"线程组" → "取样器" → "HTTP请求"
2. 重命名为"登录请求"
3. 配置参数：
   - **方法**：POST
   - **路径**：`/api/login`
   - **内容编码**：UTF-8

### 步骤6：为登录请求添加HTTP信息头管理器
1. 右键点击"登录请求" → "配置元件" → "HTTP信息头管理器"
2. 添加头信息：
   - **名称**：`Content-Type`
   - **值**：`application/json`

### 步骤7：为登录请求添加HTTP请求体
1. 右键点击"登录请求" → "配置元件" → "HTTP请求体"
2. 在"请求体"中添加：
```json
{"phone_number":"${phone_number}","password":"${password}"}
```

### 步骤8：添加Cookie管理器
1. 右键点击"线程组" → "配置元件" → "HTTP Cookie管理器"
2. 重命名为"HTTP Cookie管理器"
3. 配置参数：
   - **清除每次迭代的Cookie**：不勾选
   - **由线程组控制**：不勾选

### 步骤9：添加主页面请求
1. 右键点击"线程组" → "取样器" → "HTTP请求"
2. 重命名为"主页面请求"
3. 配置参数：
   - **方法**：GET
   - **路径**：`/`

### 步骤10：为主页面请求添加响应断言
1. 右键点击"主页面请求" → "断言" → "响应断言"
2. 重命名为"响应断言"
3. 配置参数：
   - **要测试的响应字段**：响应文本
   - **模式匹配规则**：包含
   - **要测试的模式**：`亿政通`

### 步骤11：添加API请求-领导动态
1. 右键点击"线程组" → "取样器" → "HTTP请求"
2. 重命名为"API请求-领导动态"
3. 配置参数：
   - **方法**：GET
   - **路径**：`/api/key-persons`
4. 在"参数"标签页添加：
   - **名称**：`businessPersonId`，**值**：`e7558fb6-234c-475d-82b9-79db46840389`
   - **名称**：`page`，**值**：`1`
   - **名称**：`pageSize`，**值**：`30`

### 步骤12：添加API请求-通知
1. 右键点击"线程组" → "取样器" → "HTTP请求"
2. 重命名为"API请求-通知"
3. 配置参数：
   - **方法**：GET
   - **路径**：`/api/notification`

### 步骤13：添加监听器
1. **查看结果树**：
   - 右键点击"线程组" → "监听器" → "查看结果树"
   - 重命名为"查看结果树"

2. **汇总报告**：
   - 右键点击"线程组" → "监听器" → "汇总报告"
   - 重命名为"汇总报告"

3. **聚合报告**：
   - 右键点击"线程组" → "监听器" → "聚合报告"
   - 重命名为"聚合报告"

## 🔧 配置验证

### 验证CSV数据文件
1. 在"用户数据文件"配置中，点击"浏览"按钮
2. 选择 `docs/test-users.csv` 文件
3. 确保文件路径正确

### 验证变量引用
1. 在"登录请求"的请求体中，确保使用 `${phone_number}` 和 `${password}`
2. 这些变量会从CSV文件中读取

## 🚀 运行测试

### 测试前检查
1. 确保服务器运行在 `localhost:3002`
2. 确保 `docs/test-users.csv` 文件存在且格式正确
3. 确保所有配置元件都正确设置

### 开始测试
1. 点击工具栏的绿色"启动"按钮
2. 观察"查看结果树"中的请求情况
3. 查看"汇总报告"和"聚合报告"中的性能指标

## 📊 预期结果

- **登录请求**：成功率 > 95%
- **主页面请求**：成功率 > 95%

3. **错误率**：关注汇总报告中的错误百分比

## 🛠️ 故障排除

### 问题1：CSV文件找不到
**解决方案**：
- 检查文件路径是否正确
- 确保文件名是 `docs/test-users.csv`
- 检查文件编码是否为UTF-8

### 问题2：变量未正确替换
**解决方案**：
- 检查CSV数据文件配置中的变量名称
- 确保请求体中使用正确的变量名 `${phone_number}` 和 `${password}`

### 问题3：登录失败
**解决方案**：
- 检查服务器是否正常运行
- 验证用户凭据是否正确
- 检查HTTP信息头是否正确设置

### 问题4：Cookie不生效
**解决方案**：
- 确保Cookie管理器配置正确
- 检查登录响应是否包含Cookie
- 验证后续请求是否正确使用Cookie

## 🎯 保存测试计划

配置完成后，保存测试计划：
1. 点击"文件" → "保存测试计划为"
2. 选择保存位置
3. 文件名建议：`多用户测试计划-手动配置.jmx`

这样配置的测试计划应该能够正常工作，避免XML兼容性问题。
