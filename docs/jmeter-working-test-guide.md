# JMeter工作测试计划使用指南

## 🎯 概述

`jmeter-working-test.jmx` 是一个完全兼容JMeter 5.6.3的测试计划，避免了所有XML兼容性问题。

## 📁 文件说明

### 核心文件
- **`jmeter-working-test.jmx`** - 工作测试计划（推荐使用）
- **`test-users.csv`** - 用户数据文件

## 🚀 使用方法

### 步骤1：加载测试计划
1. 打开JMeter
2. 加载 `jmeter-working-test.jmx`
3. 确认成功加载，无错误提示

### 步骤2：配置登录请求体
由于XML限制，需要手动配置登录请求的请求体：

1. **选择登录请求**：
   - 在左侧树形结构中点击"登录请求"

2. **配置请求体**：
   - 在右侧面板中，切换到"Body Data"标签页
   - 在文本框中输入：
   ```json
   {"phone_number":"${phone_number}","password":"${password}"}
   ```

3. **验证配置**：
   - 确保"Send Parameters With The Request"选项已勾选
   - 确保"Use multipart/form-data for POST"选项未勾选

### 步骤3：验证CSV数据文件
1. 选择"用户数据文件"配置
2. 确认文件路径指向 `docs/test-users.csv`
3. 确认变量名称为 `phone_number,password`

### 步骤4：开始测试
1. 点击工具栏的绿色"启动"按钮
2. 观察"查看结果树"中的请求情况
3. 查看"汇总报告"和"聚合报告"中的性能指标

## 📊 测试配置

### 当前配置
- **并发用户数**：1000
- **启动时间**：60秒
- **循环次数**：1
- **服务器地址**：`localhost:3002`

### 测试流程
1. **登录请求**：使用CSV数据中的用户凭据
2. **Cookie管理**：自动保存和传递认证Cookie
3. **主页面请求**：访问主页面并验证响应

## 🔧 故障排除

### 问题1：登录请求失败
**解决方案**：
- 检查请求体是否正确配置
- 确认CSV文件中的用户信息正确
- 验证服务器是否正常运行

### 问题2：CSV变量未替换
**解决方案**：
- 检查CSV数据文件配置
- 确认变量名称正确
- 验证文件路径和编码

### 问题3：Cookie不生效
**解决方案**：
- 确保Cookie管理器配置正确
- 检查登录响应是否包含Cookie
- 验证后续请求是否正确使用Cookie
