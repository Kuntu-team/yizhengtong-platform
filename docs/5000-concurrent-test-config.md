## ⚠️ 风险控制

### 潜在风险
1. **本地硬件限制**：可能超出CPU/内存承受能力
2. **数据库连接爆满**：接近6000连接上限
3. **网络拥塞**：本地网络带宽限制
4. **系统不稳定**：可能导致服务崩溃

### 应急措施
1. **立即停止**：`npm run pm2:stop`
2. **监控资源**：实时观察CPU/内存使用
3. **数据库监控**：关注连接数使用情况
4. **降低并发**：根据实际情况调整JMeter线程数
