# 🌐 页面测试JMeter配置指南

## 📊 测试目标
测试 `http://localhost:3002/` 页面的完整加载性能

## 🎯 测试方案对比

### 方案1：基础页面测试（推荐）
**测试范围：** 主页面 + 关键静态资源
**适用场景：** 快速验证页面基本性能

### 方案2：完整页面测试
**测试范围：** 主页面 + 所有静态资源 + API调用
**适用场景：** 完整的用户体验测试

### 方案3：混合测试
**测试范围：** 页面加载 + 关键API接口
**适用场景：** 综合性能测试

## 🔧 方案1：基础页面测试配置

### 1. 线程组设置
```
线程数: 1000
Ramp-Up时间: 60秒
持续时间: 180秒
循环次数: 1
```

### 2. HTTP请求默认值
```
协议: http
服务器名称或IP: localhost
端口号: 3002
```

### 3. 主页面请求
```
名称: 主页面
方法: GET
路径: /
```

### 4. 关键静态资源请求
```
名称: CSS文件
方法: GET
路径: /globals.css

名称: 主要JS文件
方法: GET
路径: /_next/static/chunks/main.js

名称: 页面JS文件
方法: GET
路径: /_next/static/chunks/pages/index.js
```

### 5. 监听器配置
- **查看结果树**：查看详细请求响应
- **汇总报告**：查看性能统计
- **聚合报告**：查看响应时间分布

## 🔧 方案2：完整页面测试配置

### 1. 使用HTTP(S)测试脚本记录器
```
1. 启动JMeter的HTTP(S)测试脚本记录器
2. 配置浏览器代理到JMeter
3. 访问 http://localhost:3002/
4. 停止记录器
5. JMeter自动生成完整的测试计划
```

### 2. 优化生成的测试计划
```
- 移除不必要的请求
- 添加断言验证页面内容
- 配置合理的并发参数
```

- **页面加载时间** < 3秒
- **首字节时间** < 1秒

## ⚠️ 注意事项

### 1. 资源依赖
- 确保所有静态资源路径正确
- 检查图片、字体等大文件
- 验证API接口可用性

### 2. 会话管理
- 如果页面需要登录，先进行登录
- 使用Cookie管理器保持会话
- 处理可能的CSRF令牌

### 3. 数据验证
- 添加响应断言验证页面内容
- 检查关键元素是否存在
- 验证API返回数据格式

## 🚀 快速开始

### 1. 创建基础测试计划
```
1. 新建测试计划
2. 添加线程组
3. 添加HTTP请求默认值
4. 添加主页面请求
5. 添加关键资源请求
6. 添加监听器
```

### 2. 运行测试
```
1. 保存测试计划
2. 设置线程数（建议从100开始）
3. 点击开始按钮
4. 观察结果
```

### 3. 分析结果
```
1. 查看汇总报告
2. 分析响应时间分布
3. 检查错误率
4. 优化配置参数
```
